# River Islands Connect

A community app for River Islands (Lathrop, CA) residents that consolidates WhatsApp groups into a unified platform.

## Vision

Replace 10+ fragmented WhatsApp groups with one organized community hub featuring:
- Community feed with categorized discussions
- Local marketplace (buy/sell/free/services)
- Direct messaging
- Event calendar (post-MVP)
- Service directory with reviews (post-MVP)
- Tool sharing/lending (post-MVP)

## Tech Stack

| Layer | Technology |
|-------|------------|
| Mobile | React Native + Expo |
| Backend | Supabase (PostgreSQL, Auth, Storage, Realtime) |
| Language | TypeScript |
| State | Zustand + React Query |
| Navigation | Expo Router |
